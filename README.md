# ANA — دستیار شخصی هوشمند

ANA یک دستیار دسکتاپ فارسی‌محور و ماژولار است. هدف نسخه اول، ساخت مغز مکالمه‌ای با شخصیت قابل ویرایش، حافظه قابل مدیریت، گفت‌وگوی متنی و صوتی، و معماری قابل تعویض برای مدل‌ها و آواتارهاست.

## تصمیم‌های محصول

- زبان اصلی: فارسی ایران (fa-IR)
- مغز: Hybrid — سرویس‌های آنلاین و مدل محلی اختیاری
- آواتار: پشتیبانی هدفمند از Live2D و VRM
- صدا: قابل انتخاب و تعویض
- معماری: ماژولار؛ مغز، شخصیت، حافظه، ASR، TTS و آواتار مستقل‌اند
- ترتیب: ابتدا مکالمه و شخصیت؛ سپس صدا و آواتار؛ بعد بینایی و کنترل سیستم با مجوز

## وضعیت فعلی

این مخزن در شروع فقط یک README کوتاه داشت. شاخه `phase-1/persian-brain-foundation` اسناد معماری و شخصیت اولیه را اضافه می‌کند. هنوز کد برنامه، اتصال واقعی به سرویس مدل، رابط کاربری یا مکالمه صوتی در این شاخه پیاده‌سازی و آزمایش نشده است.

## اصول ایمنی و حریم خصوصی

- هیچ API key یا رمز عبوری در مخزن ذخیره نمی‌شود.
- ارسال حافظه، فایل، تصویر صفحه، میکروفون یا دوربین به سرویس ابری باید تحت کنترل و رضایت روشن کاربر باشد.
- کنترل ویندوز، اجرای فرمان، حذف فایل و نصب برنامه در فاز اول غیرفعال می‌مانند.
- قابلیت‌های پروژه‌های دیگر فقط پس از بررسی مجوز کد و دارایی‌های جانبی و تست مستقل وارد می‌شوند.
